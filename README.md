# MyTempo 节拍器

一个极简、免费的网页版节拍器，适合吉他、贝斯等乐器练习。

## 在线使用

👉 **https://xu-jhdbl.github.io/mytempo/**

（手机 Safari 直接打开即可，无需安装）

## 功能

- 速度 40–240 BPM（滑杆 / 加减按钮 / 打拍定速）
- 节拍型：2/4、3/4、4/4、5/4、6/8、7/8、9/8、12/8
- 音效：经典 / 木鱼 / 电子 / 踩镲
- 重音开关、音量调节、视觉节拍灯珠

## 本地使用

直接双击 `index.html` 用浏览器打开即可。

## 技术说明

- 计时采用 Web Audio API 的**前瞻调度（lookahead scheduler）**，采样级精准
- 音色全部由代码合成（正弦衰减 + 噪声包络），零资源依赖、无版权问题

> 原生 iOS 版（SwiftUI）源码见 `MyTempo/` 目录。
